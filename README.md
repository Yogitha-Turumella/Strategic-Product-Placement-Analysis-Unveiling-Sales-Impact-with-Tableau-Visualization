📌 Strategic Product Placement Analysis
Unveiling Sales Impact with Tableau Visualization
📖 Project Overview

This project analyzes the impact of product placement strategies on sales performance using interactive Tableau visualizations integrated into a Flask web application.

The objective is to identify how product positioning, category trends, and sales distribution influence overall revenue and customer purchasing behavior.

The project combines data analytics, visualization, and web integration to deliver an interactive dashboard accessible through a browser.

🎯 Objectives

Analyze product placement impact on sales.

Identify high-performing product categories.

Track sales trends over time.

Visualize KPIs for business insights.

Deploy Tableau dashboard using Flask framework.

🚀 How to Run the Project
Step 1: Install Flask
pip install flask
Step 2: Run the Application
python app.py
Step 3: Open in Browser
http://127.0.0.1:5000/

The Tableau dashboard will load inside the web page.
